GODMODE is an AI development app for Windows. It helps you work with Claude Code and manage AI agents in one place. It also supports cross-model checks with Claude, GPT, and Gemini, so you can compare answers before you act.

## 🏁 First Run

After you open GODMODE for the first time:

1. Let the app finish loading.
2. Choose the AI model or models you want to use.
3. Pick a skill that fits your task.
4. Add your request in plain language.
5. Review the output before you use it.
6. If needed, run the task again with a different model.

For best results, keep your request short and clear. For example, ask the app to review code, plan a feature, or compare two choices.
